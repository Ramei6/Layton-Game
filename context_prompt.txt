## CRITICAL: Coordinate System
DevTools reports VIEWPORT pixels, not game-space pixels.
When transform:scale() is active (e.g. 0.75×), DevTools coords are WRONG.

The project uses a calibration helper in game.js:
- Click anywhere on the game → console logs game-space x/y
- Press C → copies "left: Xpx; top: Ypx;" to clipboard
- A red ✓ bubble appears at the clicked spot to confirm

## DialogueEngine (dialogue.js)
DialogueEngine.start(lines, onComplete)
  lines: [{ character, portrait, side, text }]
  - portrait maps to assets/characters/{portrait}-idle.png + -talk.png
  - side: 'left' or 'right' — portrait position
  - Omit portrait field entirely for no-portrait lines
  - 'gabriel' is in MIRRORED_PORTRAITS set → scaleX(-1) applied
  - Portrait opacity set to 0, class applied, src set, THEN onload

  - Click 1 during typing: skips to end of current line
  - Click 2: advances to next line or calls onComplete
  - Cat companion 🐱 badge shows if GameState.catFound === true
  - Dialogue box slides up from bottom via GSAP on start
  - Slides back down on end
  - NO_TALK_ANIM set: portraits with idle-only assets skip animation

## Naming Conventions

## Sprite vs Zone Architecture
- All CHARACTER SPRITES are <img> elements in #scene-sprites
- All CLICK ZONES are <div> elements in #scene-sprites (appended after)
- All HINT COINS are <div> elements in #scene-hotspots

- _setupZones() receives container as argument, does NOT clear
- _setupHotspots() clears #scene-hotspots independently

## Portrait System
- Portraits cycle between -idle and -talk during typewriter
- Gabriel's portrait is mirrored (in MIRRORED_PORTRAITS Set)
- The flip-artifact bug is fixed: opacity→0, apply class, set src,
  onload → opacity→1 (prevents old portrait flipping before swap)
- Talk animation uses setInterval at 190ms
- To disable talk anim for a portrait: add to NO_TALK_ANIM Set

## Coordinate System
- ALL positions are in 1280×720 logical space
- Use calibration tool in game.js (click + C to copy)
- Always measure at scale(1) / fullscreen
- Sprites: use top + left (never bottom for new positions)
- Zones: top-left corner + width + height
- Coins: top-left corner (44×44px fixed size, subtract 22 from center)

## Scene Architecture Pattern
Each scene module follows this pattern:
  init() → SceneManager.goTo(id, callback, bgSrc)
  callback:
    _setupSprites()    clears #scene-sprites, adds imgs, calls _setupZones
    _setupHotspots()   clears #scene-hotspots, adds coins
    _showLocationTag() fades in/out location name
  _setupZones(container) appends invisible click divs
  _showExclamation(onComplete) → red ! bubble above character
  onXxxSolved() → called by puzzle, returns to scene

## GSAP Patterns
- Slide in: gsap.from(el, {x:-200, opacity:0, duration:0.7})
- Fade in:  gsap.fromTo(el, {opacity:0}, {opacity:1, duration:0.5})
- Shake:    gsap.to(el, {x:8, duration:0.07, repeat:5, yoyo:true})
- Coin pop: gsap.to(coin, {scale:1.6, opacity:0, y:-35, duration:0.55})
- Float:    gsap.to(el, {y:-9, duration:2.4, repeat:-1, yoyo:true})
- DelayedCall must be stored in variable and killed if scene changes

## js/scenes/scene-title.js
```javascript
const SceneTitle = {
  _phase: 0,
  _clickHandler: null,
  _pulseDelay: null,

  init() {
    this._phase      = 0;
    this._pulseDelay = null;
    gsap.set('#title-subtitle',    { opacity: 0, y: 18 });
    gsap.set('#title-press-start', { opacity: 1, scale: 1 });

    SceneManager.goTo('screen-title', () => {
      gsap.delayedCall(0.5, () => this._startPulse('slow'));
      gsap.delayedCall(0.8, () => {
        this._clickHandler = () => this._handleClick();
        document.getElementById('screen-title')
          .addEventListener('click', this._clickHandler);
      });
    });
  },

  _startPulse(speed) {
    gsap.killTweensOf('#title-press-start');
    const duration = speed === 'fast' ? 0.55 : 1.2;
    gsap.to('#title-press-start', {
      opacity: 0.55, scale: 0.96, duration,
      repeat: -1, yoyo: true, ease: 'sine.inOut',
    });
  },

  _handleClick() {
    if (this._phase === 0) {
      this._phase = 1;
      gsap.to('#title-subtitle', { opacity:1, y:0, duration:0.75,
        ease:'power2.out' });
      this._pulseDelay = gsap.delayedCall(0.8,
        () => this._startPulse('fast'));

    } else if (this._phase === 1) {
      this._phase = 2;
      if (this._pulseDelay) { this._pulseDelay.kill();
        this._pulseDelay = null; }
      document.getElementById('screen-title')
        .removeEventListener('click', this._clickHandler);
      gsap.killTweensOf('#title-press-start');
      gsap.to('#title-press-start', {
        opacity: 0, duration: 0.12, repeat: 5, yoyo: true, ease: 'none',
        onComplete: () => SceneIntro.init(),
      });
    }
  },
};
```

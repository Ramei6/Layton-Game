## What this is
A browser-based point-and-click puzzle game built as a birthday gift.
It is a love letter to the Professor Layton game series, personalised
with real names, real places (Venice + Mestre, Italy), and inside jokes.

The recipient is the developer's girlfriend (Dasha). The developer is Gabriel.
The game must be finished and playable by Tuesday night (2026-07-22).

## How it runs
- Single HTML entry point: index.html
- No build tool, no npm, no framework
- GSAP 3.12.5 loaded via CDN for animation
- All other code is vanilla HTML + CSS + JavaScript
- Delivered as a zipped folder — recipient opens index.html in Chrome
- Runs in Codespaces (GitHub) with Live Server on port 5500

## Fixed canvas size
1280 × 720 px. Scaled to fit any screen via JS transform:scale().
All coordinates in CSS and JS are relative to this 1280×720 space.

## Puzzle 1 — The Gondola Crossing (River Crossing / Missionaries & Cannibals)
CLASSIC PUZZLE TYPE: River crossing with constraint.

CHARACTERS: Dasha (adult), Gabriel (adult), Signora Rossi (adult), Kid1 Luca, Kid2 Sofia, Kid3 Marco
BOAT: Max 2 passengers, min 1 to cross
CONSTRAINT: On any bank, if there are 1+ adults AND kids outnumber adults → INVALID (kids cry, reset)
EXCEPTION: A bank with ONLY kids and ZERO adults is valid (MC classic rule)
WIN: All 6 characters on Bank B, boat empty

UI:
- Left panel: description + hints
- Right panel: Bank A | Gondola column | Bank B
  - Character tokens (emoji + label) in each bank
  - Click token on current bank → boards gondola (max 2)
  - Click token on gondola → disembarks back to current bank
  - "Cross" button → validates constraints, moves boat+passengers to other side
  - "Reset" button → resets to initial state
  - Status bar shows feedback messages

ON SOLVE → PuzzleShell shows "Brilliant deduction!" → Continue → Scene1Bridge.onPuzzleSolved()

## Mental model
The game is one HTML page. All "screens" are <div> elements stacked
with position:absolute inset:0. Only one has display:block at a time.
SceneManager fades between them using GSAP.

## Game loop per scene
1. SceneManager.goTo('screen-scene', callback)
2. Scene module sets background image src
3. Scene module injects sprites into #scene-sprites
4. Scene module injects hotspot coins into #scene-hotspots
5. Click handlers on sprites call DialogueEngine.start() or PuzzleShell.open()
6. After dialogue or puzzle resolves, scene updates state and re-renders if needed

## Game loop per puzzle
1. PuzzleShell.open(config) is called from a scene
2. PuzzleShell calls SceneManager.goTo('screen-puzzle')
3. PuzzleShell populates header, description, hint area
4. PuzzleShell calls config.init(rightPanelElement) — puzzle injects its own UI
5. Hint button calls config hints array, costs 1 hint coin
6. Submit button calls config.checkSolution() → true/false
7. On correct: shows celebration overlay, then calls config.onSolve()
8. onSolve() returns control to the calling scene module

## State machine
GameState object is global (defined in state.js, loaded first).
All scenes and puzzles read from and write to GameState.
No persistence (no localStorage) — game is single-session.

const Scene2StMarco = {

  init() {
    document.getElementById('scene-background').src = 'assets/backgrounds/scene2-stmarco.jpg';
    SceneManager.goTo('screen-scene', () => {
      this._setupSprites();
      this._setupHotspots();
      this._showLocationTag('Venice — Piazza San Marco');
    });
  },

  _setupSprites() {
    const container = document.getElementById('scene-sprites');
    container.innerHTML = '';

    // Tourist with birds — only if puzzle 2 not yet solved
    if (!GameState.puzzlesSolved.p2) {
      const tourist = document.createElement('img');
      tourist.src       = 'assets/sprites/scene-tourist-birds.png';
      tourist.id        = 'sprite-tourist';
      tourist.className = 'clickable-sprite';
      Object.assign(tourist.style, {
        position: 'absolute', bottom: '90px', left: '260px', height: '280px'
      });
      tourist.addEventListener('click', () => this._onTouristClick());
      // Slight panic shake loop
      gsap.to(tourist, {
        rotation: 2, duration: 0.3, repeat: -1, yoyo: true,
        ease: 'sine.inOut', transformOrigin: 'bottom center'
      });
      container.appendChild(tourist);
    }

    // Carnival character — only if puzzle 2 solved AND puzzle 3 not yet solved
    if (GameState.puzzlesSolved.p2 && !GameState.puzzlesSolved.p3) {
      const carnival = document.createElement('img');
      carnival.src       = 'assets/sprites/scene-carnival.png';
      carnival.id        = 'sprite-carnival';
      carnival.className = 'clickable-sprite';
      Object.assign(carnival.style, {
        position: 'absolute', bottom: '90px', right: '220px', height: '290px',
        opacity: '0'
      });
      carnival.addEventListener('click', () => this._onCarnivalClick());
      container.appendChild(carnival);

      // Slide in from right
      gsap.fromTo(carnival,
        { x: 200, opacity: 0 },
        { x: 0, opacity: 1, duration: 0.7, ease: 'power2.out' }
      );
    }
  },

  _setupHotspots() {
    const container = document.getElementById('scene-hotspots');
    container.innerHTML = '';

    const coins = [
      { id: 'scene2-coin1', style: { top: '60px',  left: '80px'  } },
      { id: 'scene2-coin2', style: { top: '140px', left: '700px' } },
      { id: 'scene2-coin3', style: { top: '320px', left: '1100px'} },
    ];

    coins.forEach(({ id, style }) => {
      if (GameState.collectedCoins.scene2.has(id)) return;
      const coin = document.createElement('div');
      coin.className = 'hintcoin';
      Object.assign(coin.style, style);
      coin.addEventListener('click', (e) => {
        e.stopPropagation();
        GameState.collectedCoins.scene2.add(id);
        GameState.addHintCoin();
        gsap.to(coin, { scale: 1.6, opacity: 0, y: -35, duration: 0.5,
          onComplete: () => coin.remove() });
      });
      container.appendChild(coin);
    });
  },

  _showLocationTag(text) {
    const tag = document.getElementById('scene-location-tag');
    tag.textContent = text;
    gsap.fromTo(tag,
      { opacity: 0, y: -10 },
      { opacity: 1, y: 0, duration: 0.5, delay: 0.3,
        onComplete: () => gsap.to(tag, { opacity: 0, duration: 0.5, delay: 2.5 })
      }
    );
  },

  _onTouristClick() {
    if (GameState.puzzlesSolved.p2) return;
    DialogueEngine.start([
      { character: 'Tourist', portrait: 'tourist', side: 'left',
        text: "Help! HELP! They just keep coming! I only had a sandwich!" },
      { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
        text: "Sir, calm down. How long have you been standing there?" },
      { character: 'Tourist', portrait: 'tourist', side: 'left',
        text: "Since 10am! The square fills completely at noon! I need to know when to run!" },
      { character: 'Apprentice Gabriel', portrait: 'gabriel', side: 'right',
        text: "Each bird calls another, and they arrive one per minute..." },
      { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
        text: "A classic doubling problem. Gabriel — when is the square half full?" },
    ], () => {
      Puzzle2Pigeons.open();
    });
  },

  _onCarnivalClick() {
    if (GameState.puzzlesSolved.p3) return;
    DialogueEngine.start([
      { character: '???', portrait: 'carnival', side: 'left',
        text: "Brava, Detectives. That was most impressive." },
      { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
        text: "Who are you?" },
      { character: '???', portrait: 'carnival', side: 'left',
        text: "A friend. I have been watching your deductions with great interest." },
      { character: '???', portrait: 'carnival', side: 'left',
        text: "Consider this a gift. It will show you where your next adventure begins." },
      { character: 'Apprentice Gabriel', portrait: 'gabriel', side: 'right',
        text: "A... map?" },
      { character: '???', portrait: 'carnival', side: 'left',
        text: "Buona fortuna, Ispettore." },
    ], () => {
      Puzzle3Map.open();
    });
  },

  // Called by Puzzle2Pigeons on solve
  onPigeonsSolved() {
    DialogueEngine.start([
      { character: 'Tourist', portrait: 'tourist', side: 'left',
        text: "11:59?! I have 59 more minutes of this?! NOOO—" },
      { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
        text: "Run, sir. Run now." },
      { character: 'Apprentice Gabriel', portrait: 'gabriel', side: 'right',
        text: "Inspector... there's someone watching us from the arcade..." },
    ], () => {
      GameState.puzzlesSolved.p2 = true;
      this._setupSprites(); // re-render: tourist gone, carnival appears
    });
  },

  // Called by Puzzle3Map on solve
  onMapSolved() {
    DialogueEngine.start([
      { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
        text: "Mestre. Of course — just across the Ponte della Libertà." },
      { character: 'Apprentice Gabriel', portrait: 'gabriel', side: 'right',
        text: "La Tana di Oberix... do you know the place?" },
      { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
        text: "I know we need to take the train. Come on, Detective." },
    ], () => {
      // Train transition
      document.getElementById('scene-background').src = 'assets/backgrounds/transition-train.jpg';
      document.getElementById('scene-sprites').innerHTML  = '';
      document.getElementById('scene-hotspots').innerHTML = '';
      document.getElementById('scene-location-tag').style.opacity = '0';

      // Show brief train dialogue
      setTimeout(() => {
        DialogueEngine.start([
          { character: 'Apprentice Gabriel', portrait: 'gabriel', side: 'right',
            text: "I still can't believe we're working on your birthday trip." },
          { character: 'Inspector Dasha', portrait: 'dasha', side: 'right',
            text: "We're not working. We're having an adventure. There's a difference." },
        ], () => {
          setTimeout(() => Scene3Restaurant.init(), 1500);
        });
      }, 1200);
    });
  },
};

  _renderCards(container) {
    const list = container.querySelector('#recipe-list') ||
                 document.getElementById('recipe-list');
    if (!list) return;

    list.innerHTML = '';

    // Display from top to bottom visually (reverse of array order)
    const displayOrder = [...this._currentOrder].reverse();

    displayOrder.forEach((id, displayIndex) => {
      const realIndex = this._currentOrder.length - 1 - displayIndex;
      const info = this.LABELS[id];

      const card = document.createElement('div');
      card.className = 'recipe-card';
      card.dataset.realIndex = realIndex;

      card.innerHTML = `
        <div class="position-badge">${realIndex + 1}</div>
        <span style="color:${info.color}">${info.display}</span>
      `;

      if (this._selectedIndex === realIndex) {
        card.classList.add('selected');
      }

      card.addEventListener('click', () => this._onCardClick(realIndex, list, container));
      list.appendChild(card);
    });
  },

  _onCardClick(realIndex, list, container) {
    if (this._selectedIndex === null) {
      // First click: select
      this._selectedIndex = realIndex;
      this._renderCards(container);
    } else if (this._selectedIndex === realIndex) {
      // Click same: deselect
      this._selectedIndex = null;
      this._renderCards(container);
    } else {
      // Second click: swap
      const a = this._selectedIndex;
      const b = realIndex;
      [this._currentOrder[a], this._currentOrder[b]] =
      [this._currentOrder[b], this._currentOrder[a]];
      this._selectedIndex = null;
      this._renderCards(container);
      gsap.from('#recipe-list', { x: 5, duration: 0.08, repeat: 2, yoyo: true });
    }
  },

  _checkSolution() {
    return this._currentOrder.every((id, i) => id === this.CORRECT_ORDER[i]);
  },
};

## Dialogue Engine conventions
- portrait name maps to: assets/characters/{name}-idle.png and {name}-talk.png
- side: 'left' = portrait appears on left, 'right' = on right
- The DialogueEngine swaps between -idle and -talk at 190ms interval during typing
- Clicking advances line; if still typing, first click skips to full text
- Cat companion icon 🐱 shows in dialogue box when GameState.catFound === true

## PuzzleShell conventions
- Each puzzle module exposes one public method: open()
- open() calls PuzzleShell.open(config)
- config.init(container) injects all puzzle-specific HTML/CSS into right panel
- config.checkSolution() returns boolean — called on Submit
- config.onSolve() is called after player clicks Continue on success overlay
- Hint coins cost 1 GameState.hintCoins per hint
- If no hint coins: shake animation + console message (no toast yet)
- Incorrect answer: red overlay with shake animation, player can retry freely

## SceneManager conventions
- SceneManager.goTo(screenId, callback)
- callback fires after the fade-in animation completes
- HUD (#hud) is shown automatically for 'screen-scene' and 'screen-puzzle'
- HUD is hidden for all other screens

## Sprite and hotspot re-render pattern
Each scene's _setupSprites() and _setupHotspots() reads GameState
and renders the correct version of the scene. Called:
  1. On scene init
  2. After a puzzle is solved (via onPuzzleSolved/onSomethingSolved callback)
Always clears innerHTML before re-rendering to avoid duplicates.

## CSS display conventions
- .screen { display: none } — all screens hidden by default
- SceneManager sets display:block when showing a screen
- #screen-intro needs `display: none` explicitly (NOT display:flex in CSS)
- #screen-end: do NOT put display:flex in CSS — SceneManager handles it
  #end-content uses position:absolute + transform:translate(-50%,-50%) for centering

## GSAP usage patterns
- Slide in from side:  gsap.from(el, { x: -200, opacity: 0, duration: 0.7 })
- Fade in:            gsap.fromTo(el, { opacity:0 }, { opacity:1, duration:0.5 })
- Shake (wrong):      gsap.to(el, { x:8, duration:0.07, repeat:5, yoyo:true })
- Bounce (coin):      gsap.fromTo(el, {scale:1.35}, {scale:1, duration:0.4, ease:'back.out(2)'})
- Float loop:         gsap.to(el, { y:-9, duration:2.4, repeat:-1, yoyo:true, ease:'sine.inOut' })
- Disappear:          gsap.to(el, { scale:1.6, opacity:0, y:-35, duration:0.5, onComplete: ()=>el.remove() })

If the game will be gifted as a local zip (no guaranteed internet):
1. Download: https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js
2. Save to: js/lib/gsap.min.js
3. In index.html, replace:
     <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
   with:
     <script src="js/lib/gsap.min.js"></script>
